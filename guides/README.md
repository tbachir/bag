# 🗺️ BAG Field Guides & Documentation

Documentation for BAG is organized according to the **Diátaxis framework**, dividing knowledge into four distinct modes of interaction:

```text
               PRACTICAL                   THEORETICAL
        ┌─────────────────────────┬─────────────────────────┐
        │                         │                         │
LEARNING│       Tutorials         │        Concepts         │
ORIENTED│   (Hands-on learning)   │    (Understanding &     │
        │                         │     architecture)       │
        ├─────────────────────────┼─────────────────────────┤
        │                         │                         │
ACTION  │      How-To Guides      │        Reference        │
ORIENTED│   (Goal-driven tasks)   │  (Information, schemas  │
        │                         │       & contracts)      │
        └─────────────────────────┴─────────────────────────┘
```
