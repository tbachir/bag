# reusable-component-extractor

Extract portable configurations, functions, components, skills and workflows from real projects into curated BAG items.

Read [SKILL.md](SKILL.md), [CHANGELOG.md](CHANGELOG.md), and [BAG freshness policy](../../../maps-and-guides/skill-freshness-policy.md). This skill is opt-in; merely cataloging it does not activate an agent's skill loader.

## Delegate

```text
Use this BAG skill for the relevant task in my project.
BAG item: https://github.com/tbachir/bag/tree/main/skill-tree/skills/reusable-component-extractor
Read BAG root and applicable nested AGENTS.md files. Inspect SKILL.md and freshness metadata, invoke the skill-maintainer workflow if stale, then inspect my project, propose/implement authorized changes and report evidence and tests.
```
