# 🤖 Agents

Guides and reusable instruction patterns for AI assistants, multi-agent workflows, handoffs, role boundaries, and project-specific `AGENTS.md` files.

Start from [AGENTS.example.md](AGENTS.example.md). Adapt it to the target project's actual architecture, tools, commands, and permissions rather than copying assumptions across repositories.

This repo's [root AGENTS.md](../../AGENTS.md) governs **BAG itself**; it is not a global instruction file.

**Status:** starter template ready; agent profiles to be curated.
