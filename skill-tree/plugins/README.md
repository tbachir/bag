# 🧩 Plugins

A place to evaluate plugins/connectors used by developer assistants and workflows.

Record **provider, official URL, compatible clients, available actions, requested permissions, data access, pricing/limits if applicable, and review date**. Avoid assuming a plugin can be used until the account/client has installed or connected it.

Never store authorization tokens here. Prefer least-privilege scopes and document revocation steps.

**Status:** shelf ready; plugins to be curated.
