# Interactive demonstrations

Small standalone examples of BAG concepts. These are prototypes, not production applications.

- [Task Composer](task-composer.html) — select Supabase Auth tasks and copy a concise delegation prompt. Open the HTML file locally in a browser.
- [Composer documentation](../maps-and-guides/task-composer.md)

The prototype embeds demo data; the [task manifest](../inventory/supabase/auth/tasks/index.json) remains the source of truth for future production integrations.
