# Identity Forge — visual systems for coding agents

Identity Forge provides visual kits combining typography, semantic light/dark color tokens, layout guidance and component rules for web projects and coding agents.

- **Category:** Design resource / hosted service
- **Status:** evaluating — primary-source documentation reviewed; exports and integrations not tested
- **Official source:** [Kit browser](https://identityforge.io/kits)
- **Documentation:** [Overview](https://identityforge.io/docs)
- **Commercial access:** [Current pricing](https://identityforge.io/pricing); see the access caveat below
- **License:** No open-source license established by this review; verify service, kit and font usage terms before reuse
- **Last reviewed:** 2026-10-29
- **Compatibility:** Web design workflows; documented exports include CSS variables, Tailwind configuration, DESIGN.md, shadcn/ui registry, JSON tokens and Style Dictionary. Compatibility with any particular project version remains untested.

## Why keep it?

A kit supplies more design context than a palette alone: font choices, spacing and component conventions can help an agent maintain a coherent interface. Use it to compare visual directions before introducing a project's design tokens.

## Practical use

1. Browse kits on a surface similar to the target product, such as a dashboard or editorial page.
2. Compare the candidate with the project's current branding, typography, components and light/dark modes.
3. Verify current export access and usage terms, then inspect the selected export before applying it.
4. Map approved values to existing semantic tokens and document the rationale in a project-local DESIGN.md. Check contrast, focus states and representative screens in both themes.

The documentation describes CLI, MCP and API access. This card does not validate their installation commands, permissions or behavior and does not require installing them.

## Access and limitations

The official documentation overview says most kits and all export formats are free without an account. The official pricing comparison instead places complete tokens, implementation guidance, agent-ready exports and registry access in Pro. These statements conflict as of the review date: verify access for the selected kit directly rather than relying on a free-access promise. Prices and catalog counts are intentionally omitted here.

Treat exported agent rules as design reference material, subject to the target project's instructions. A kit does not establish accessibility compliance or native React Native compatibility. Review font licensing and delivery separately.
