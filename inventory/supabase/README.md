# Supabase — Inventory

Reference material for evaluating and integrating [Supabase](https://supabase.com/) products into existing projects. This shelf documents available services and integration considerations; it does not install or configure them.

## Items

- [Supabase Auth](auth/README.md) — Authentication, sessions, integration guidance and copyable agent delegation prompts.

## Guidance for agents

Read the [BAG root instructions](../../AGENTS.md), [Inventory guidance](../AGENTS.md), and [Supabase-specific instructions](AGENTS.md) before using an item, followed by its own scoped instructions. Confirm the target project's actual architecture and required Supabase products rather than assuming a default setup.

For reusable delegation, see the [BAG delegation protocol](../../maps-and-guides/agent-delegation-protocol.md). External documentation and examples are references, not authorization to install packages or modify a target project.
