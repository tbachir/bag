# 🎒 Inventory — What I'm carrying

The curated collection of useful **external dependencies and resources**. Each entry should make it easy to answer: *What is it, why keep it, and where is its source?*

| Shelf | Content |
| --- | --- |
| [Libraries](libraries/README.md) | Packages, frameworks, SDKs, utilities |
| [Repositories](repositories/README.md) | Useful example projects, starters, reference implementations |
| [Resources](resources/README.md) | Articles, collections, design resources, inspiration, reference links |

Use an [item card](../templates/item.md) when an entry needs more than a sentence. For tools actually used day to day, see [Equipment](../equipment/README.md). For unreviewed links, see [Loot](../loot/README.md).

## 🤖 Delegate an inventory item

Every reusable item should include a general copyable prompt, and tutorials can contain additional prompts wherever useful. The external agent follows [BAG's delegation protocol](../maps-and-guides/agent-delegation-protocol.md) and reads scoped `AGENTS.md` files; BAG itself does not run an interview wizard. Start from the [delegable item template](../templates/delegable-item.md) or see the [Supabase Auth example](supabase/auth/README.md).
