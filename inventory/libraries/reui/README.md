# ReUI

A library of composed shadcn-based application patterns: data grids, forms, filters, calendars and dashboards.

- **Official source:** https://reui.io/components
- **Role:** Curated reference, not an automatic project dependency.
- **Recommendation:** recommended for react, nextjs, dashboard when the project needs this capability.
- **Reviewed:** 2026-10-29

## Practical workflow

1. Audit the project's current React framework, UI primitives, dependencies and tokens.
2. Consult the official source and evaluate the smallest compatible solution.
3. Integrate only after reviewing installation steps, licenses and potential collisions.
4. Verify accessibility, responsiveness, reduced motion, theme variants and automated tests.

## Trade-offs

ReUI examples are not universally drop-in; read any third-party packages and distinguish Radix versus Base UI implementations.
