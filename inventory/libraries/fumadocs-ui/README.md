# Fumadocs UI

Documentation components and page layouts for Fumadocs, including tabs, steps, tables, files and search.

- **Official source:** https://www.fumadocs.dev/docs/ui/components
- **Role:** Curated reference, not an automatic project dependency.
- **Recommendation:** mandatory for fumadocs, documentation, nextjs when the project needs this capability.
- **Reviewed:** 2026-10-29

## Practical workflow

1. Audit the project's current React framework, UI primitives, dependencies and tokens.
2. Consult the official source and evaluate the smallest compatible solution.
3. Integrate only after reviewing installation steps, licenses and potential collisions.
4. Verify accessibility, responsiveness, reduced motion, theme variants and automated tests.

## Trade-offs

Server-only examples, optional plugins and Graph View require distinct setup. See the BAG UI Workbench for supported components.
