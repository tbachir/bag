# 📚 Libraries

A curated shelf for packages, frameworks, SDKs, and developer utilities.

Add entries as needed, grouped by ecosystem (TypeScript, React, Node.js, databases, mobile, etc.). Each entry should include:

- Name + official repository or docs URL
- What problem it solves and when to choose it
- Platform/runtime compatibility, license, maintenance status
- Trade-offs and alternatives worth remembering

For more detail, create a file using [the item template](../../templates/item.md) and link it here. Prefer official primary sources over stale roundup articles.
