## Why keep it?

A curated reference for 20 workflows spanning game architecture, combat, monsters, maps, rigging, audiovisual feedback, mobile controls, performance, browser QA and delivery. The [individual skill catalog](../../../skill-tree/skills/game-development/README.md) provides the complete inventory and usage boundaries without duplicating the upstream source.

## When to use it

When a project requires a focused game-development process and an agent can inspect and adapt the source instructions to its own platform and repository constraints. Read the narrowest skill, evaluate potential overlap, and verify acceptance tests in the actual target.

## Safety and limits

Project-specific Vesperfall procedures need adaptation. No package, asset or script from the upstream repository is implicitly approved for installation or execution. License and source checks apply to all copied materials. Upstream methods have not been run inside BAG.
