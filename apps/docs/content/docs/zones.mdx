BAG is a recursive inventory: **every folder can be an item**, with its own documentation,
optional metadata and as many nested items as necessary. The seven original zones remain
storage conventions, not seven competing workflows or a limit on item types.

## Manage and reuse an item

1. Open its README and read its scope, sources, limitations and nested items.
2. Follow its applicable `AGENTS.md` and consult its `SKILL.md` when the item is a skill.
3. Use the item's prompt and optional task tree to delegate a specific goal.
4. Review prerequisites, freshness and proposed changes before installing or executing anything.

## Advanced: repository structure

[Equipment](https://github.com/tbachir/bag/blob/main/equipment/README.md) holds configurations,
[Loot](https://github.com/tbachir/bag/blob/main/loot/README.md) holds discoveries awaiting review,
and [the catalog](https://github.com/tbachir/bag/blob/main/catalog/README.md) describes machine-readable references.
These are useful storage and lifecycle conventions, not separate kinds of items or mandatory navigation steps.
