BAG is a curated, searchable inventory for developers and AI agents. Explore its
seven zones to find libraries, tools, skills, scripts, guides, discoveries, and
compositions for a particular workflow.

The repository remains the source of truth for BAG's inventory. These docs link
to the existing material so each item keeps one primary home.

## Search locally

From a BAG checkout, use the dependency-free catalog CLI:

```bash
node spellbook/scripts/bag.mjs search "agents" --json
node spellbook/scripts/bag.mjs loadout ai-coding --json
```

Read the [catalog and loadouts guide](https://github.com/tbachir/bag/blob/main/maps-and-guides/catalog-and-loadouts.md)
before applying equipment. Inspect the plan and explicitly approve the target
before running `equip --apply`.
