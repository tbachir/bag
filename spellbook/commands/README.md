# ⌨️ Commands & recipes

Keep short terminal recipes here, grouped by OS or tool. Each recipe should declare its shell (PowerShell, Bash, etc.), intended working directory, prerequisites, and what files it changes.

Avoid `curl ... | sh` and destructive commands without clear review steps. For larger repeatable logic, create a documented script under [Scripts](../scripts/README.md).
