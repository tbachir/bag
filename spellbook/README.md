# 📖 Spellbook — Reusable magic

Scripts, command recipes, snippets, and automations with clear prerequisites and safe behavior.

| Chapter | Purpose |
| --- | --- |
| [Scripts](scripts/README.md) | Runnable helpers, including the BAG search and documentation validator |
| [Commands](commands/README.md) | Copyable terminal recipes and OS-specific tips |

Every script should say what it does, which platforms it supports, what it modifies, and how to verify the result. Prefer standard libraries and minimal dependencies.
