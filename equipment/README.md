# ⚔️ Equipment — Tools you can equip

Tools, apps, environment setups, and ready-to-adapt configuration files.

| Slot | Purpose |
| --- | --- |
| [Tools](tools/README.md) | Developer applications, CLIs, IDEs, productivity tooling |
| [Configs](configs/README.md) | Safe default config templates and setup notes |

**Equipment vs Inventory:** Inventory stores promising resources; Equipment documents **practical daily tooling and setup**. Nothing in BAG silently installs or activates software.

See [Loadouts](../loadouts/README.md) for curated combinations.
