## Validate your documentation build

Choose the package manager already used by your project.

<Tabs items={['pnpm', 'npm']}>
  <Tab value="pnpm">Run `pnpm build`.</Tab>
  <Tab value="npm">Run `npm run build`.</Tab>
</Tabs>

Check output, broken links, search and static deployment paths before publishing.
