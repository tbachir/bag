# ⚙️ Configurations

Reusable **non-sensitive** configuration defaults. Copy/adapt them deliberately; nothing in this folder is applied automatically.

Starter examples:

- [`.editorconfig.template`](.editorconfig.template): shared text formatting baseline.
- [`.gitignore.template`](.gitignore.template): general Node/TS project ignore rules.

When adding a template, mention target tool, supported versions, variables to customize, and whether settings are opinionated. Sensitive values belong in environment variables or a secret manager, not the repository.
