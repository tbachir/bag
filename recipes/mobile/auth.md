# Authentication and authorization

## Objective

Audit Supabase Auth mobile and Better Auth admin boundaries against the target app. Verify session lifecycle, user/organization roles, invitations, access controls, RLS and sign-out behavior before adding providers. Avoid exposing service-role credentials or mixing distinct auth authorities.

## Acceptance checks

A threat-aware auth and RLS checklist, migration impact assessment, and target-specific test plan are documented.
