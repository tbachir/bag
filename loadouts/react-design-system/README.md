# React · Coherent Design System

A real, reviewable BAG loadout. The machine-readable composition is in [catalog/loadouts/react-design-system.json](../../catalog/loadouts/react-design-system.json), not duplicated here.

**Best for:** React/Next.js dashboards and application shells.

1. Read existing design tokens and write a compatible DESIGN.md.
2. Choose and document Radix *or* Base UI variants before mixing primitives.
3. Use shadcn for core primitives and ReUI for higher-level patterns where beneficial.
4. Review spacing, responsive layouts, keyboard access, forms, loading and dark mode.
5. Extract only reusable components with tests and component ownership notes.

**Acceptance criteria:** No duplicated foundational libraries, consistent theme, keyboard-visible focus, responsive layout and relevant screenshot tests.
