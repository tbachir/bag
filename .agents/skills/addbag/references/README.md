# Add to BAG — reference materials

These files are bundled with [the addbag skill](../SKILL.md). They define a reusable capture-scoring rubric and an approval-ready proposal format; the agent does not need to expose all of these internals in every invocation.

- [Curation rubric](curation-rubric.md) — prioritize reusable, evidenced knowledge and reject private or low-value material.
- [Plan template](plan-template.md) — propose precise BAG paths and ask for **one** explicit approval before editing.
