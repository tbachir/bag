# Docs Architect

[Use the **docs-architect** skill](SKILL.md) for a project- and reader-aware information architecture. It is framework-agnostic, with a dedicated adapter for native Fumadocs navigation, MDX components, optional metadata and static publishing.

This is the single canonical BAG skill. The former `documentation-architect` location is only a compatibility pointer.

## Delegate: audit and improve documentation

```text
Use https://github.com/tbachir/bag/tree/main/skill-tree/skills/docs-architect.
Read BAG's root-to-item AGENTS.md chain and this skill, then inspect my project's own instructions, current documentation, Fumadocs versions and navigation. Propose an audience-based page tree, a migration/redirect map and safe incremental implementation. Preserve canonical source Markdown and optional metadata; do not move or delete files without assessing consumers. Validate the build and links, and report precisely what was tested.
```
