# 💎 Loot — Interesting, not yet equipped

The **inbox** for discoveries, experiments, inspiration, and rabbit holes worth revisiting.

Start with [inbox.md](inbox.md), then inspect provenance, trust, license, compatibility, and real usefulness. Promote valuable items into the appropriate permanent zone; archive or discard the rest. Loot is intentionally less curated than Inventory.

**Rule:** a link found online is not a vetted recommendation or an invitation to execute its code.
