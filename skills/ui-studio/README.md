# UI Studio & Prototype Generator

Inspect any project, extract or validate its `design/DESIGN.md`, inventory screens and components, audit dead features, and generate an interactive UI prototype and documentation studio.

## Purpose

Generates a standalone, zero-dependency `ui-studio.html` file that serves as an interactive prototype studio with mobile/desktop device preview frames, route specifications, component gallery, and code health checklist.

## Installation

```bash
bag skill add ui-studio --target ./my-project
```

Or via npx:
```bash
npx skills add tbachir/bag --skill ui-studio
```
