# 🧠 Agent Skill Scaffold Template

Canonical starter template for creating new Agent Skills conforming to the Agent Skills standard.

## File

- [`SKILL.md`](SKILL.md): Standard skill layout with name, description, purpose, procedures, and prompt blueprints.

## Usage

```bash
bag template apply skills/SKILL.md --target ./my-project/.agents/skills/my-new-skill
```
