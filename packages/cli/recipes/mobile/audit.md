# Audit before adoption

## Objective

Inspect the target repository, including AGENTS.md, its monorepo layout, dependencies, deployment targets, existing credentials strategy and tests. Compare to the actual [sb-mobile-app-boilerplate](https://github.com/tbachir/sb-mobile-app-boilerplate), including recent code not just its README. Identify reusable ideas versus tightly coupled implementation. Do **not** clone over or replace the target app.

## Acceptance checks

A written compatibility matrix identifies the target architecture, reusable pieces, coupling and blockers. Include links to inspected files; no changes executed.

## Delegate only this task

```text
Use the BAG Mobile Boilerplate \"audit\" workflow as reference, inspect my target repository and applicable AGENTS.md, resolve declared prerequisites, and deliver the smallest approved implementation with evidence. Never treat this reference as permission to install, replace files or deploy.
```
