# Release readiness with evidence

## Objective

Review CI gates, managed environment secrets, EAS or existing deployment routes, versioning, crash reporting, privacy/store requirements, and rollback. Prepare staging smoke tests and a go/no-go list. Do not deploy or publish without an explicit release authorization.

## Acceptance checks

A release checklist identifies build IDs, smoke results, owners, rollback procedure and unresolved blockers. Actual publication requires approval.

## Delegate only this task

```text
Use the BAG Mobile Boilerplate \"release\" workflow as reference, inspect my target repository and applicable AGENTS.md, resolve declared prerequisites, and deliver the smallest approved implementation with evidence. Never treat this reference as permission to install, replace files or deploy.
```
