# 🎒 BAG Inventory Skill

Discover, evaluate, and plan approved local loadouts from the BAG developer inventory.

## Purpose

Enables AI agents to query the BAG catalog, inspect canonical resources, and generate safe, non-destructive loadout equip plans.

## Usage

```bash
bag skill add bag-inventory --target ./my-project
```

Read canonical instructions in [SKILL.md](SKILL.md).
